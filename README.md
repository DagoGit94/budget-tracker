# BudgetTracker

A Java console application that calculates monthly expenses and displays the remaining budget.

## Key Features
- Prompts the user for monthly income and expenses across four categories (Rent, Groceries, Transportation, Entertainment).
- Calculates total expenses and remaining balance.
- Calculates the percentage of income spent on each category.

## What I Practiced
- Handling user input and validating data types using `java.util.Scanner`.
- Performing arithmetic operations and using the `Math` class for rounding.
- Formatting console output for readability.

## How to Run
1. Open the project in NetBeans or VS Code.
2. Run `BudgetTacker.java` from the command line or IDE.
3. Follow the on-screen prompts to enter your budget details.
